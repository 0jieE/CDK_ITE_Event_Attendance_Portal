Use this to recover after a disaster: deploy against a new empty database (the app creates its tables and the Super Admin automatically), sign in here, then upload the file. Restoring replaces ALL current users, students, events, attendance and fines with the contents of the file. It is all-or-nothing: if the file is bad, nothing changes.
